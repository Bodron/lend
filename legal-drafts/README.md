# Documente PINLEND — versiunea 2026-10-04.1

Cele patru fișiere DOCX și Markdown din acest director sunt versiuni noi, RO/EN,
adaptate pentru funcțiile PINLEND. Texte identice sunt servite de backend prin
`GET /api/legal/documents`; amprenta SHA-256 a fiecărui document este inclusă în
dovada acceptării utilizatorului.

Fișierele originale cu numele `VERIFICAT avocat` au fost păstrate separat și
nemodificate. Această adaptare schimbă substanțial obiectul serviciului și nu
moștenește verificarea juridică a documentelor originale. Versiunile de aici
necesită o nouă verificare juridică înainte de publicare.
